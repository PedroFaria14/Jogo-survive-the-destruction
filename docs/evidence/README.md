# Evidências de execução

As capturas nesta pasta são geradas por `frontend/tests/e2e/game.spec.js`, usando o jogo real e um backend local, sem simular snapshots ou resultados de partida.

- `home-desktop.png`: apresentação do projeto.
- `home-mobile.png`: home em retrato (390 × 844).
- `personalizacao-mobile.png`: formulário antes da conexão.
- `partida-desktop.png`: partida com dois clientes independentes.
- `partida-mobile.png`: gameplay em paisagem e controles de toque reais no Chromium emulado.
- `home-projeto.png`: mecânicas, controles e apresentação técnica abaixo da primeira dobra.

Para reproduzir, consulte [o roteiro de demonstração](../demonstracao.md). Resultados de execução e limitações são registrados nesse roteiro; a presença de um arquivo de imagem, sozinha, não comprova toda a suíte.
